# 제출 기록 (과제 3, 보존용)

과제 제출 당시 README에 있던 확인 방법과 AI 판단 기록입니다.

## 확인 방법 (테스트 가이드)
1. **어디로 가나요?** https://ilb72.github.io/meme-card-studio/ (새 시크릿 창에서 접속)
2. **3단계 이내 무엇을 하나요?** 이미지 업로드 → 템플릿 이름 입력 후 [저장] 클릭 → 목록에서 [불러오기] 클릭
3. **무엇이 보이면 통과인가요?** 올린 이미지와 텍스트가 화면에 정상 출력되고, 템플릿 목록이 복원됨
4. **안 될 때 무엇이 보이나요?** 잘못된 파일(PDF/txt 등) 업로드 시 에러 메시지가 표시됨

## AI와 나의 판단
1. **AI에게 맡긴 일:** 캔버스 렌더링 기본 로직, 템플릿 CRUD(localStorage) 초기 코드 작성, JSON 검증 로직 초안 작성
2. **직접 판단한 일:** 텍스트 줄바꿈 기준을 단어가 아닌 '글자 단위'로 변경하여 해결, 이미지 저장 시 용량 초과(QuotaExceededError)를 막기 위해 썸네일 압축(JPEG 0.7) 저장 방식 도입 및 예외 처리 적용
3. **AI 제안을 따르지 않은 일:** AI가 제안한 이모지 전용 렌더링 함수는 실제 결함이 이모지가 아닌 'ㅁ' 텍스트 연속 입력이었으므로 제외함
